## 4. 本阶段做了什么

**后端**
- 新增 `batches` 表；`generation_jobs` 加 `batch_id`、`sku_code` 两列（启动时幂等补列）
- `services/csv_import.py`：编码探测（UTF-8-sig → UTF-8 → GBK）、表头校验、逐行校验（行长/重复/必填）、缺图行标 skipped、200 行上限
- `services/batch_runner.py`：线程池（默认 3）+ **并发预算预约**（锁保护，避免 3 个 worker 同时冲过预算）+ 断点续跑
- `services/export_zip.py`：ZIP 流式打包（图片按 sku_code 命名、清单、账单），同 SKU 不覆盖
- 7 个接口：validate / create / trial / confirm / resume / cancel / retry-item / list / detail / events(SSE) / export
- 启动时把 `running` 批次转 `paused`，可续跑

**前端**
- 新增批量页 `/projects/[id]/batch`（01 上传 → 02 试跑 → 03 进度 → 04 结果）
- 坏表逐行报错表（行/列/原因）
- 试跑闸门：没试跑过不能确认批量
- 批次 SSE 进度条 + 每完成一条就地出图
- 停止 / 继续 / 单条重试 / 导出
- 刷新后自动找回最近批次（从后端列表接口恢复）
