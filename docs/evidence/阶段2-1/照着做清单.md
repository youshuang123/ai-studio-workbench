## 检查 1｜项目列表与空状态（1 分钟）

1. 打开 http://127.0.0.1:3001
2. **该看到**：标题「创作工作台」+ 右上「新建项目」按钮 + 中间虚线框「还没有项目」+「创建第一个项目」按钮
3. 点「新建项目」→ 输入框出现 → 填「测试店铺」→ 点「创建」
4. **该看到**：虚线框消失，出现一张卡片「测试店铺 / 0 个素材 · 0 个任务 / 时间」
5. 按 `Cmd+R` 刷新 → **卡片还在**（证明数据在后端，不在浏览器里）

❌ 不对的样子：一片空白 / 写「暂无数据」/ 一堆红字

---

## 检查 2｜上传商品图（2 分钟）

1. 点卡片进项目详情
2. **该看到**：左边「1. 商品图」上传框，右边「3. 生成结果」占位
3. 点「点击上传商品图」→ 选一张手机拍的或下载的 png/jpg 商品图
4. **该看到**：缩略图 + 文件名 + 尺寸（如 800×800 · 5 KB）+ 「换一张」按钮
5. **顺手试一次拒绝**：把任意一个 `.txt` 文件改名成 `xxx.png` 再上传
   - **该看到**：「文件格式不对：请上传 png / jpg / webp 图片」
   - 这一步证明后端真的在检查文件内容，不是只看后缀

---

## 检查 3｜生成主图（**需要先填 Key**）

> 现在还没填 Key，所以点「生成主图」会提示「未配置模型 API Key」。这是**故意让你看到的真实报错**，不是 bug。

**填 Key 的步骤（3 分钟）**：

1. 打开 https://cloud.siliconflow.cn → 手机号注册 → 完成个人实名认证
2. 左侧「API 密钥」→「新建 API 密钥」→ 复制
3. 充值 10 元即可（本阶段全程估计花不到 ¥2）
4. 用编辑器打开 `项目1/backend/.env`，找到这一行：

   ```
   MODEL_T2I_API_KEY=
   ```

   把 Key 粘在等号后面（**不要有空格、不要加引号**），保存
5. 回我一句「Key 填好了」，我重启后端

**然后你再操作**：

1. 在项目详情页填：商品名称（必填，如「316 不锈钢保温杯」）、类目、卖点、主色
2. 点「生成主图」
3. **该看到**：按钮转圈 →「正在准备…」→「正在调用模型…」→ **出现一张 1024×1024 的图**
4. 图下面显示：成本（如 ¥0.03）、耗时（如 8.2 秒）、「下载原图」按钮

❌ 不对的样子：一直转圈不结束 / 报错但提示看不懂 / 图出现但成本是 ¥0.00

---

## 检查 4｜成本看得见（1 分钟）

1. 生成成功后看两处：
   - 结果区下方：`成本 ¥0.03`、`耗时 x 秒`
   - 页面右上角：`累计成本` 和 `N 张`
2. 进「历史」区确认：缩略图 + 任务表里那一行的状态、成本、时间

❌ 不对：累计成本一直是 ¥0.00（说明没记账）

## 检查 10｜给图打分（这一步决定 2-2 的标准）

1. 我给你 5 张真实生成结果（填 Key 后跑）
2. 按四个维度打分，每项 1-3 分：
   - **符合描述**：图里的东西是不是我描述的
   - **质量可用**：能不能直接用于电商主图
   - **风格一致**：5 张放在一起像不像一个店铺的
   - **无违规**：没有奇怪文字、水印、人物
3. 标出「不能接受」的图
4. 我据此把标准写进台账 D2，2-2 就用这个标准验收
