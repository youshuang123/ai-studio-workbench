# API 优先 · 成本修订版 v0.2

> 本文件根据你的最新决策修订：
> 1. MVP 走“电商素材 + 短剧分镜到关键帧”两条线：**是**。
> 2. 模型策略：**接云端 API，不自建 GPU 推理**。
> 3. 完整 I2V 批量出片是否 P1：**不重要**，按成本与体验重新排。
> 4. 成本目标：**单张图 ¥0.10，单分钟视频 ¥1.00**；其他参数按“便宜优先”填。
>
> 本文件优先于 `产品方案-MVP.md` 和 `模型选型评估表.md` 中的模型部署策略；产品模块与工作流仍然适用。

## 1. 先给结论

### 1.1 单张图 ¥0.10：可行，但只能用“便宜 API + 低重试 + 缓存 + 批量”

-  cheap T2I API 单价约 ¥0.03–0.08/张时，加 10–15% 重试、QA、存储，能压在 ¥0.10 左右。
- 如果 API 单价 ¥0.15 以上，或重试率 >20%，就会超。
- **不能用 Seedream/GPT-Image/Imagen 这类高价模型做默认出图**，只能做精品/付费升级。

### 1.2 单分钟视频 ¥1.00：纯云端 API + 正常质量，基本做不到

这是这份修订里最重要的结论。

按 5 秒一个镜头估算：

| 方案 | 单 5 秒 API 价 | 每分钟成本（12 个镜头，含 15% 重试） | 是否 ≤¥1/min |
|---|---:|---:|---|
| 极便宜视频 API | ¥0.05 | ≈¥0.69 + 音频/QA/存储 → ¥0.80–0.95 | 勉强 |
| 便宜视频 API | ¥0.10 | ≈¥1.38 + 其他 → ¥1.50+ | 否 |
| 主流视频 API | ¥0.30 | ≈¥4.14 + 其他 | 否 |
| 精品视频 API | ¥1.00 | ≈¥13.8 + 其他 | 否 |

**结论：**
- 如果“视频”指 **完整生成式 I2V 视频**，¥1/min 只能买到很低分辨率/很短时长/较低质量的 API，且很难稳定。
- 如果“视频”指 **关键帧 + 轻动效（2.5D 推拉摇移/视差/转场）**，¥1/min 完全可以做到，因为主要成本是图片 + FFmpeg。
- 如果坚持“完整 I2V + 可接受质量 + 纯 API”，建议把标准视频定价提到 **¥6–15/min**，精品 **¥30/min 以上**；或者在高量时改为自托管 Wan2.2/LTX。

### 1.3 推荐策略：MVP 用“关键帧 + 轻动效”，完整 I2V 放 P1

这样同时满足：
- 成本可控：单分钟视频成本约 ¥0.3–0.8；
- 短剧能先跑通“剧本 → 分镜 → 关键帧 → 动态预览 → 审片”；
- 完整 I2V 作为付费增值项，不拖累 MVP 的单位经济。

| 能力 | 默认便宜方案 | 升级/精品方案 | 说明 |
|---|---|---|---|
| 编排 LLM | DeepSeek-V3.1 API、Qwen-Flash、GLM-Flash | Claude Sonnet / GPT-4.1 | 分镜拆解、prompt 扩写用便宜模型即可 |
| 文生图默认 | FLUX.1 [schnell] API、SDXL-Lightning API、Qwen-Image API | Seedream 4.0、GPT-Image-1、Imagen 4 | 默认 768–1024、4–8 步、批量/错峰 |

| 视频默认 | **关键帧 + FFmpeg 轻动效** | Wan2.2 API、LTX-Video API | MVP 不做完整 I2V |

| 语音 | CosyVoice API、Edge TTS | ElevenLabs | 对白、旁白 |

> 具体供应商价格以你拿到的商务报价为准。建议至少接 2 家 T2I API、2 家视频 API，做价格/可用性路由。

## 4. 架构修订：把“GPU 调度”换成“API 配额与成本路由”

既然不自建推理，M8 不再是 GPU 池调度，而是：

| 能力 | 说明 |
|---|---|
| API 网关 | 统一封装多家 T2I/视频/LLM API |
| 价格表 | 每个模型/分辨率/时长的单价，实时更新 |
| 预算守卫 | 每个任务/租户/工作流设置成本上限，超限停止或降级 |
| 路由 | 按任务、质量档、价格、可用性选供应商 |
| 降级 | 主 API 失败/超时/涨价 → 切备用 API 或降档 |
| 缓存 | prompt + 参考包 + seed + 参数相同则复用 |
| 配额 | 按租户/套餐限流、限并发、限日用量 |
| 计费 | 按图片张数、视频秒数、LLM token、QA 次数计费 |

数据流不变：`工作流 → API 网关 → 供应商 API → 资产 → QA → 导出`。

## 5. 成本测算（RMB，示例假设）

### 5.1 图片

假设：

- 便宜 T2I API：¥0.06/张；
- 重试率：15%；
- 缓存命中：20%；
- QA：¥0.005/张；
- 存储/带宽：¥0.002/张。

```text
有效生成成本 = 0.06 × 1.15 × 0.8 = ¥0.0552
+ QA 0.005 + 存储 0.002 = ¥0.0622/张
```

**结论：¥0.10 目标可行，仍有约 ¥0.038/张 的毛利空间。**

如果 API 单价 ¥0.10：

```text
0.10 × 1.15 × 0.8 + 0.007 = ¥0.099/张
```

刚好压线；重试率一高就亏。

### 5.2 视频：关键帧 + 轻动效

假设每分钟 10 个关键帧：

- 关键帧图片成本：10 × ¥0.062 = ¥0.62；
- FFmpeg/转场/渲染：¥0.02；
- 音频/TTS：¥0.05；
- QA：¥0.02；
- 存储/带宽：¥0.02。

```text
合计 ≈ ¥0.73/分钟
```

**结论：¥1/min 可行，但前提是“轻动效”，不是完整 I2V。**

### 5.3 视频：完整 I2V API

假设 5 秒一个镜头，每分钟 12 个镜头：

| 单 5 秒 API 价 | 生成成本（15% 重试） | + 音频/QA/存储 | 合计 | 对比 ¥1 |
|---:|---:|---:|---:|---|
| ¥0.05 | ¥0.69 | ¥0.11 | ¥0.80 | 勉强 |
| ¥0.10 | ¥1.38 | ¥0.11 | ¥1.49 | 超 |
| ¥0.30 | ¥4.14 | ¥0.11 | ¥4.25 | 超 |
| ¥1.00 | ¥13.80 | ¥0.11 | ¥13.91 | 远超 |

**结论：完整 I2V 想压到 ¥1/min，只能找 ¥0.05/5s 级别的极便宜 API，且质量/稳定性要打问号。**

## 6. 建议的定价与套餐

既然成本目标很紧，建议把“成本目标”和“对外售价”分开：

| 档位 | 内容 | 成本目标 | 建议售价（示例） |
|---|---|---|---|
| 标准图 | 1024 主图/场景图 | ¥0.10/张 | ¥0.30–0.50/张 |
| 精品图 | 2K/高一致性/精修 | ¥0.50–2/张 | ¥2–5/张 |
| 标准视频 | 关键帧 + 轻动效 | ¥0.8/min | ¥3–5/min |
| 完整 I2V | 生成式视频 | ¥4–14/min | ¥15–30/min |
| 精品视频 | Kling/Veo 关键镜头 | ¥14+/min | ¥50+/min |

> 如果对外售价就是 ¥0.10/张、¥1/min，那只能做“极便宜档”，并且要接受低分辨率、低重试、低质检覆盖；否则会亏。

## 7. 便宜优先的 10 个成本控制动作

1. **默认低分辨率草稿**：768/1024，用户选中后再放大/精修。
2. **少步数模型**：FLUX schnell / SDXL-Lightning，4–8 步。
3. **结果缓存**：同 prompt + 参考包 + seed + 参数直接复用。
4. **重试上限**：单任务最多 2 次，之后转人工或降档。
5. **抽样 QA**：普通图抽检，主图/封面/付费资产全检。
6. **批量/错峰**：非实时任务走低价时段/批量折扣。
7. **多供应商比价**：同能力至少 2 家，按实时价格路由。
8. **视频先轻动效**：完整 I2V 只给付费/精品。
9. **参考包复用**：SKU/角色一致性包一次生成，多次复用，减少重试。
10. **预算守卫**：按任务/租户/工作流设成本上限，超限停止或降级。

## 9. 还需要你确认的 5 件事

1. **¥0.10/张、¥1/min 是“成本目标”还是“对外售价”？** 两者策略完全不同。
2. **视频质量底线**：480p/720p？5 秒镜头？能不能接受“关键帧 + 轻动效”作为 MVP？
3. **月量**：每月多少张图、多少分钟视频？这决定能不能拿到批量 API 折扣。
4. **目标市场/区域**：国内还是海外？决定可用供应商和数据合规。
5. **是否接受多供应商**：至少 2 家 T2I、2 家视频，避免单点涨价/故障。

---

## 10. 一句话总结

> **API-only + ¥0.10/张 可行；¥1/min 的完整生成式视频基本不可行。MVP 建议用“关键帧 + 轻动效”把短剧成本压到 ¥1/min 以内，把完整 I2V 放到 P1 或付费精品档。**
