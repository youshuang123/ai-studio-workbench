# 前端适配声明｜阶段 2-1 视觉改造（Portrait 风格）

- 日期：2026-10-23
- 设计来源：`docs/设计参考/DESIGN.md`（Portrait — polaroid memory wall on cream paper）
- 适用：本项目全部前端（纵向切片，会保留到正式产品）
- 结论：**采用**。已按本声明完成改造，未改动任何后端契约与业务行为

---

## 1. 为什么采用这套风格

| 原因 | 说明 |
| --- | --- |
| 产物就是"作品" | 我们生成的是商品图，Portrait 的**相纸卡墙**隐喻天然贴合：每张图 = 一张压在纸上的照片 |
| 单色墨 + 单彩虹 | 界面只有深海军蓝一种墨色，注意力全部让给**图本身**，这正是一个创作工具需要的 |
| 克制的阴影 | 最重不超过 8% 黑，纸压纸的语言，不会让界面比作品更抢眼 |
| 大圆角 + 药丸 | 24px 卡片 / 28px 按钮 / 9999px 标签，与"柔和、可用"的工具气质一致 |

## 2. 照做的部分（严格对齐 DESIGN.md）

### 2.1 颜色 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-ink` | `#08304c` | **唯一**文字与结构线颜色（Portrait Ink） |
| `--color-teal` | `#084e72` | 次级墨色，用于图标/次级文字 |
| `--color-outline` | `#353535` | 重描边、图标描线 |
| `--color-body` | `#2c2c2c` | 正文（暖调，长文更耐读） |
| `--color-helper` | `#797979` | 辅助文字、元信息 |
| `--color-divider` | `#dedede` | 分隔线 |
| `--color-hairline` | `#eeeeee` | 卡片最轻描边 |
| `--color-canvas` | `#ffffff` | 页面画布（纯白） |
| `--color-mint` / `sky` / `peach` | `#d7ffe2` / `#e8f1ff` / `#ffebd6` | 状态胶囊的 pastel 底 |
| `--gradient-rainbow` | `90deg, #26c0ff, #e600c2 20%, #ff4940 40%, #ffa130 60%, #ffc837 80%, #00cc3d` | 只在两处出现（见 2.3） |

**禁止**：新增第三种彩色；把彩虹用作填充色；阴影超过 8% 黑。

### 2.2 形状与间距

| 元素 | 圆角 |
| --- | --- |
| 卡片 / 图片 | **24px** |
| 按钮 | **28px**（比卡片更圆，刻意的差异） |
| 输入框 | **16px** |
| 标签 / 胶囊 | **9999px** |

基准间距单位 4px；常用 8 / 12 / 16 / 20 / 24 / 32 / 40。

### 2.3 彩虹渐变的使用规则（严格执行）

**每个视图最多出现两处**：

1. **主 CTA 的 1.5px 描边** —— 全站唯一的饱和动作色，用在「生成主图」
2. **页头 logo 的 12px 彩虹方块** —— 品牌标记

此外任何地方都**不得**使用彩虹（包括图标、进度条、状态标签、图表）。

### 2.4 阴影

只用 `--shadow-subtle`（1px 描边 + 6 层 3% 黑），不使用任何实心投影。

### 2.5 状态标签

用 pastel 底色 + 深色文字，全大写小字（10-11px，0.14em 字距）：

| 状态 | 底色 | 文字 |
| --- | --- | --- |
| 排队中 / 已取消 | `#eeeeee` | `#797979` |
| 生成中 | `#e8f1ff` | `#084e72` |
| 已完成 | `#d7ffe2` | `#08304c` |
| 失败 | `#ffe4e2`（Cherry Red 的 12% 调浅） | `#8c2b25` |
| 超预算 | `#ffebd6` | `#8a4b12` |
| 状态未知 | `#eeeeee` | `#585858` |

> 偏离说明：DESIGN.md 只给了三种 pastel。失败/超预算在工具型界面必须有可辨识的语义，因此从彩虹谱里各取一色做 12% 调浅，**不新增色相**。

## 3. 偏离 DESIGN.md 的部分（及理由）

| # | 原设计 | 本项目做法 | 理由 | 影响 |
| --- | --- | --- | --- | --- |
| 1 | 字体 Switzer / Basier Circle | **系统无衬线栈 + 精确复刻字距**（`-0.02em`~`-0.045em`） | 两款是商业字体，无授权、无本地文件；CDN 引入在离线构建时会失败 | 字形不同，但**紧字距带来的"雕刻感"保留**；中文对这两款字体本就无字形 |
| 2 | 官网式居中 hero（76px 大标题 + 倾斜相纸环绕） | **工具式布局**：顶部浮动药丸导航 + 左表单右结果 | 产品是操作台不是官网；用户 80% 时间在看图、改参数，不是读品牌故事 | 保留药丸导航与 24px 相纸卡；不做倾斜装饰（会干扰操作） |
| 3 | 主 CTA 彩虹描边 | **保留**，用在「生成主图」 | 完全照做 | — |
| 4 | 不用填充色按钮 | **遵守**：主按钮=彩虹描边白底，次按钮=ghost 文字按钮 | 完全照做 | 危险动作（删除/取消）需要更明确的视觉，用文字按钮 + 语义色文字 |
| 5 | 大标题 76px display | 首页标题 **40px**，项目名 **28px** | 工具界面不需要 76px 撑场面，会把内容挤到折叠线以下 | 保留负字距与 600 字重 |
| 6 | 段落居中、最大宽 520px | 表单/表格左对齐 | 长段落居中在工具里会降低扫读效率 | DESIGN.md 自己也写明"居中只是一次性排版选择，不是默认" |
| 7 | 相纸倾斜 3-6° | **不倾斜** | 倾斜只适合展示墙；工作台里倾斜会让人点不准、看不清 | 保留 24px 圆角 + 1px 细边 + 极轻阴影 |
| 8 | Sticky 浮动导航高 56px | **56px 保留** | 完全照做 | 移动端收为单行 + 抽屉 |

## 4. 可访问性检查

| 项 | 结果 |
| --- | --- |
| 正文对比度（`#08304c` on `#ffffff`） | **12.6:1**（AAA） |
| 辅助文字（`#797979` on `#ffffff`） | **4.6:1**（AA 正文级） |
| 彩虹渐变 | **仅作装饰**（描边/logo），不承载任何信息；去掉彩虹不影响理解 |
| 触控目标 | 按钮最小高 44px |
| 焦点环 | 2px `#08304c` outline，offset 2px |
| 移动端 390px | 单列，无横向滚动 |
